# TAANA - Modern Fashion E-Commerce Website

A premium and responsive fashion e-commerce website built using HTML, CSS, and JavaScript.

## 🌐 Live Demo
https://katil9529.github.io/Taana-store/

- Modern and responsive UI
- Product catalog
- Shopping cart

- Checkout page
- Order history
- Clean and elegant design
- Mobile-friendly layout

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
